# 便签生成规则

当用户提到 inbox 中有新任务需要处理时，通过 AskUserQuestion 工具确认意图并生成便签。

## 流程

1. 扫描 `inbox/` 下的子文件夹，列出每个文件夹及其内容（文件名、类型、大小）
2. 使用 **AskUserQuestion** 工具向用户提问，收集处理意图和关键细节（如输出格式、语言、风格、篇幅等）
3. 根据用户回答，在对应任务文件夹内生成便签 `task.md`

## 约束

1. 必须使用 AskUserQuestion 工具交互，不要直接假设用户意图
2. 一个文件夹 = 一个任务 = 一张便签（`{文件夹}/task.md`）
3. 便签中必须明确：涉及的文件、用户需求、选定的 skill、处理步骤
4. 生成便签后，询问用户是否立即处理。用户确认后才执行，否则留给 inbox-monitor loop 轮询处理。不得自行决定立即处理
5. inbox-monitor loop 每次扫描时，检查各文件夹内是否存在 `task.md` 来识别待处理任务
