# Q1 培训方案修订

## 文件
- 培训方案修订/现行培训方案.docx
- 培训方案修订/学员反馈汇总.xlsx

## 需求
根据 Q1 学员反馈修订现行培训方案，产出两个文件：
1. **修订后的培训方案.docx** — 在原文档基础上修改，保持原结构，针对低满意度课程和高频问题调整课时、改进教学方式、更新课程内容
2. **修订对照表.xlsx** — 列出每一处改动：原内容、修订内容、修订依据（对应哪条反馈）

## 处理方案
- Skill: minimax-xlsx + minimax-docx（组合使用）
- 步骤:
  1. 用 minimax-xlsx 读取并分析学员反馈数据，提取低满意度课程和高频问题
  2. 用 minimax-docx 读取现行培训方案，基于分析结果修订方案内容
  3. 用 minimax-xlsx 生成修订对照表（原内容 / 修订内容 / 修订依据）
  4. 两个产出物保存至任务文件夹
