AI Workbench

Claude Code 驱动的自动化办公工作区

v v v

概览

AI Workbench 是一个基于 Claude Code 的自动化办公工作区。将待处理文档投入 inbox/，系统自动识别文件类型、路由到对应 Skill 处理，产出物自动归档并更新索引。

项目架构：inbox 投递 → tasks 处理 → archive 归档，三层索引同步更新

快速上手

1

Clone 项目

git clone https://github.com/keta1930/ai-workbench.git
cd ai-workbench
2

初始化项目

在 Claude Code 中发送以下提示词：

阅读本项目的 README.md，然后初始化工作区。
3

了解项目

告诉我这个项目能做什么、是如何运转的。
就这么简单：两段提示词，Claude 替你完成所有配置工作。之后把任务文件夹丢进 inbox/ 就行了。

处理流程

一个任务走完全程就 5 步：投递文件、写便签定方案、选 Skill 处理、产出结果、更新索引提交 Git。你只参与前两步。

投递 → 便签 → 路由 → 产出 → 提交

Skill 路由

写便签时，你和 Claude 一起决定用哪个 Skill 处理。以下是文件类型与 Skill 的对应关系。

处理流程详情

投递任务

将任务文件夹放入 inbox/，每个文件夹 = 一个任务，可包含多个源文件。

inbox/
├── Q1分析/
│   ├── data.xlsx
│   └── template.docx
└── 会议纪要/
    └── recording.pdf

生成便签

告诉 Claude 你的处理意图，它会生成 task.md 便签，记录需求和处理方案。

## 需求
按模板生成 Q1 数据分析报告
## 处理方案
- Skill: minimax-xlsx
- 步骤: 读取 → 分析 → 输出

PDF 三选一

场景Skill说明
PDF → Markdownmineru提取文本内容
合并/拆分/提取pdf处理现有 PDF
生成高品质 PDFminimax-pdf设计级输出

Loop 详情

inbox-monitor 每 20 分钟

  • 扫描 inbox/ 下的子文件夹
  • 有 task.md 的文件夹进入处理
  • 移入 tasks/ 并重命名
  • 路由到 Skill 处理
  • 更新索引 + git commit

daily-routine 每 24 小时

  • 读取当天 changelog 和 git log
  • 生成日报（含复盘章节）
  • 周五额外生成周报
  • 保存到 reports/
  • 更新 README 索引
